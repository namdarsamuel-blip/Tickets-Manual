01 · Tools of the Trade

Software & Platforms

Where tickets get bought (primary), where they get sold (secondary), and the tools that watch the primary sites for you. We buy manually — no bots — so speed and the right tooling are what let us compete.

TM
Ticketmaster
Primary marketplace
  • Main primary seller for most major tours and arenas
  • Also runs "Verified Resale" — the Standard Reseller program for listing tickets back on TM itself
More info
  • Face Value Exchange is a listing type where resale is capped at the exact price you paid — no markup allowed, so there's no profit margin on a Face Value Exchange listing.
  • Delivery type must be set to Mobile, never Will Call. Will Call requires the buyer to physically pick up/check in, so there's no transferable code and the ticket can't be resold.
  • Most checkouts give a 7–8 minute timer, but some shows have no timer at all — be ready to decide immediately on those.
  • Doesn't always flag limited view seats (obstructions like beams or speakers). If a seat is limited view, disclose it on the listing — an undisclosed one risks a chargeback where the buyer keeps the seat and gets refunded.

SeatGeek
Primary + secondary
  • Used as a primary ticket source for some venues/events
AX
AXS
Primary marketplace
  • Primary ticketing platform, alternative to Ticketmaster for certain venues
SH
StubHub
Secondary marketplace
  • Use for Canadian shows and Broadway shows specifically
  • Not VividSeats for these — StubHub is the preferred secondary
VS
VividSeats
Secondary marketplace
  • The secondary market we check to compare pricing and get a sense of where a ticket will land
  • For Canadian/Broadway shows, use StubHub instead
More info
  • Prices show with fees baked in by default — always toggle fees off before comparing, or the number you see will be inflated.
  • Example: Ticketmaster shows $100, VividSeats shows $170 with fees on — but with fees off it's actually $140. You'll end up selling around $140, not $170, so pricing off the fee-inclusive number is a common, costly mistake.

02 · Getting In Early

Presales & Drops

Most good inventory never reaches general public sale. It moves through presale codes first — knowing which kind of code you're holding determines whether it's worth pursuing.

Account-specific or code-specific presales
Rule

Some presales require you to buy using the specific account that signed up (account-specific), or require a specific code tied to that signup even if the account itself doesn't matter (code-specific). Either way, keep track of exactly which account or code was used to sign up so you buy with the right one later.

Generic codes
Watch

Same code works for everyone — not tied to a specific account or signup. Because it's shared, you don't need to have signed up yourself; you can get the code from someone else. Usually not the move to rely on for hard-to-get inventory, since competition on the same code is high.

Used account
Strategy

A "used account" is one that's already at the top of the waiting list/queue for a specific show — i.e. it has standing for that event. Worth tracking which of your accounts are "used" for which shows.

Artist presale
Type

The presale you actually sign up for directly. Typically runs through Live Nation, the company that owns Ticketmaster.

Venue presale
Watch

Has its own unique code. Harder to find than other codes, but the upside is these codes tend to be generic once you do find them — so the bottleneck is sourcing the code, not competing for inventory. Runs through Ticketmaster.

Citi Card member presale
Watch out

Requires a Citi card to access. The boss's card sometimes doesn't have enough available funds when the window opens, so we're encouraged to maintain our own Citi card for this rather than relying on someone else's.

ShowsOnSale.com
Resource

Website used to find generic presale codes.

Weekly presale calendar
Rule

Standard weekly pattern across most shows, building from most restricted access to fully open:

Tuesday — Citi Card member presale

Wednesday — Artist presale (via Live Nation)

Thursday — Venue presale (via Ticketmaster)

Friday — Public on-sale, no code needed, anyone can buy

TimingPresales nominally start at 10 AM in the artist/venue's own local time zone — not 10 AM Eastern. So for someone on the East Coast, the actual window could open anywhere from 10 AM to 1 PM Eastern depending on which time zone the show is in.

03 · Evaluating a Buy

Buying Strategy

This is the part that's still being figured out as we go — how to tell if a ticket is actually worth buying. These are working notes, not fixed rules.

Core method: compare the spread
Strategy

Find the same row/section on Ticketmaster (primary) and compare it to what that same seat is going for on VividSeats (secondary), fees turned off. If the prices are close, it's probably not worth buying — there's no room for profit. If VividSeats is running meaningfully higher, roughly 40% or more above the Ticketmaster price, that gap may represent real margin and is worth a closer look.

Is it actually selling?
Strategy

A price spread alone isn't enough — check whether that section is actually moving. How long have tickets in that section been listed? When was the last actual sale in that section? If a section has been sitting for months with no sales despite presale tickets being out for a long time, that's a sign demand may not be there even if the listed price looks attractive.

Venue fit vs. artist popularity
Strategy

One input among several: check the artist's popularity (e.g. Spotify monthly listeners) against the size of the venue. An artist with a large following playing a comparatively small venue suggests low supply/high demand. An artist who may struggle to fill a much larger venue (stadium vs. their actual draw) is a sign the show might not sell out, which adds risk. Venue types worth knowing: stadiums, arenas, outdoor amphitheaters (e.g. the venue by Jones Beach), and general admission. This is one factor among others, not a standalone answer.

Demand can shift — example, not a standing rule
Example

Sometimes a specific artist is the one everyone in the industry is watching and buying right now — but that's a moving target, not a fixed list. Noah Kahan was given as a current example of that kind of artist; the underlying point is recognizing when an artist is in that position, not treating any one name as permanently a buy.

04 · Reference

Glossary

Quick lookup, A–Z. Each term has a short definition — expand for more detail on what it's used for and things to watch.

Account-specific / code-specific
A presale requiring either the exact account that signed up, or a specific code tied to that signup.
More info

Track which account or code was used to sign up so you buy with the right credentials later — using the wrong one can mean the presale access doesn't work at all.

Artist presale
A presale you sign up for directly through the artist.
More info

Typically run through Live Nation, the company that owns Ticketmaster. In the weekly presale pattern, this is usually the Wednesday window.

AXS
Primary ticketing platform, an alternative to Ticketmaster for certain venues.
Bots
Automated buying tools some competitors use to purchase tickets instantly the moment they're available.
More info

We buy manually, not with bots, so there's often no time to deliberate once something drops — speed and tooling like Phantom are what let us compete without them.

Chargeback (limited view)
What happens if an undisclosed limited-view seat gets sold and the buyer disputes it.
More info

The buyer can get a refund and still attend the show — a double loss on that ticket. This is why limited view always needs to be disclosed on the listing.

Citi Card member presale
A presale window that requires a Citi card to access.
More info

The card on hand sometimes doesn't have enough available funds when the window opens, so it's worth maintaining your own Citi card for this rather than relying on someone else's. In the weekly pattern, this is usually the Tuesday window.

DataIQ
A pricing/comp tool sourced from other brokers' actual sales data.
More info

Pulls data via a site called Automatic. Use it to sanity-check what a ticket should actually sell for before you buy or list — good to cross-check against TicketMetric.

Drop checker
A tool that monitors sale pages and alerts you the instant tickets drop or a price changes.
More info

Phantom is the one we use — it often hands you direct links straight to the listing (Ticketmaster, VividSeats, etc.) so you can act immediately instead of searching.

Face Value Exchange
A listing type where resale is capped at the exact price you paid.
More info

No markup allowed — effectively no profit margin on a Face Value Exchange listing. Worth knowing so you can recognize it and avoid ending up with this listing type unintentionally.

Generic code
A presale code that works for anyone, not tied to a specific signup.
More info

You don't need to have registered yourself — the code can be shared or sourced from someone else (e.g. via ShowsOnSale.com).

Limited view
A seat with an obstructed sightline — a beam, speaker stack, staging, etc.
More info

Ticketmaster may not flag this on its own. If a seat is limited view, disclose it on the listing — see Chargeback (limited view) for what happens if you don't.

No timer
A checkout that skips the usual countdown clock.
More info

Most Ticketmaster checkouts give you 7–8 minutes to complete a purchase. Some shows have no timer at all, forcing an immediate buy decision with no buffer to think it over.

Phantom
The drop checker / monitoring tool we use.
More info

Tells you the moment tickets drop or the price drops on Ticketmaster or other sites, and gives direct links straight to the listing so you can jump in instead of searching.
